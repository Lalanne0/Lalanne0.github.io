Liora Assistant

Production RAG Platform

Architected and shipped a retrieval-augmented generation system used daily by 150 employees via Slack. The platform runs on 5 FastAPI microservices across 13 Docker containers, ingesting multiple GB of internal data from AWS S3 into a Qdrant vector store with parent-child chunking and event-driven indexing via Redis Streams. Built with production observability (ELK, Prometheus, Grafana) and hardened with JWT/RBAC, rate limiting, and prompt-injection defences.

FastAPI Docker Qdrant Redis Streams AWS S3 Prometheus Grafana
Proprietary

Low-Latency Stock Predictor

Real-time inference optimisation

Achieved a 15-25x latency reduction (from ~100 us sklearn baseline to ~6 us) through progressive compiler-level optimisations: bypassed scikit-learn with raw NumPy, algebraically fused the StandardScaler into model weights for zero-cost normalisation, downcast to float32, and compiled the hot path via Numba @njit / LLVM. Streams live market predictions via WebSocket to a TradingView terminal with a multi-stage Docker build and synthetic data demo mode.

Python Numba NumPy WebSocket Docker LLVM

Semantix Breaker

Serves live queries against Google's 3M-word Word2Vec model and 60,000 French FastText vectors (~800 MB corpus), with vectorised NumPy distance computations for sub-millisecond response times.
