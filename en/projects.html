Liora Assistant

Production RAG Platform

Architected and shipped a retrieval-augmented generation system used daily by 150 employees via Slack. Honing MLE Skills

Agentic engineering workflow with Claude Code

A two-day experiment in running Claude Code as the main implementer while keeping every change auditable. Linear issues with explicit blocking relations are the single source of truth, and a custom /next skill dispatches up to three unblocked issues to unattended Claude Code workers, each isolated in its own git worktree and cmux workspace. Every worker writes tests first with ub-mode, must pass CRAP-score, duplication and mutation-testing gates, clicks through the UI with Playwright MCP, and gets at most two CodeRabbit review rounds. A /land skill merges only when CI and review pass on the exact commit it checked, rebases the workers still running and starts the next batch. Guardrails live in a project CLAUDE.md and a narrow command allow-list. The product itself is an LLM-graded ML system-design interview trainer.

Low-Latency Stock Predictor

Real-time inference optimisation

Achieved a 15-25x latency reduction (from ~100 µs sklearn baseline to ~6 µs) through progressive compiler-level optimisations: bypassed scikit-learn with raw NumPy, algebraically fused the StandardScaler into model weights for zero-cost normalisation, downcast to float32, and compiled the hot path via Numba @njit / LLVM. Streams live market predictions via WebSocket to a TradingView terminal with a multi-stage Docker build and synthetic data demo mode.
